# Fonts

Roboto Regular, Medium, Bold and Black (`Roboto-*.ttf`), copied unchanged from the Flutter SDK
(`bin/cache/artifacts/material_fonts/`). Roboto is by Google, licensed under the Apache License 2.0
(`Roboto_LICENSE.txt`). Bundled so the controller's text looks the same on a phone that is on a Wi-Fi
without internet; Flutter web would otherwise fetch Roboto from fonts.gstatic.com at run time.
