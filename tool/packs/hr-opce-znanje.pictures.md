# hr-opce-znanje: picture sourcing

Sourced 2026-11-20 for the content lead (queue task qitem-20261120143701-7140f031657b5db2, pack 1 of 12). Not a pack change: no pack file was touched.

**Numbering:** keyed to the NEW numbers of hr-opce-znanje (397 questions, commit 08a5663), with the old number in brackets: `Q<novi> (stari <n>)`. The four dropped questions (old 64, 228, 295, 375) are skipped. Question text in each block is the OLD wording; old 23, 26, 164, 243, 271, 325 and 368 were reworded on 2026-11-20, so match them by number and answer, not by text.

**Count:** 195 pictures for 397 questions = 49 %. That is 4 short of 50 % (199). The shortfall is where Commons had nothing usable or the rate limit blocked the search (see "Preskočeno / sumnje" per batch below).

**Size plan:** about 195 × 20 KB = 3.9 MB at 640 px, under the 5 MB limit (and under the 10 MB the person allowed). Several originals are huge (Mona Lisa 94 MB, Starry Night 44567×35291, Great Wave 8242×5640): download a scaled Commons thumbnail (standard widths such as 640 or 1280), not the original.

## How it was checked

- Each file's licence, author, pixel size and mime came from the Commons API. Only PD, CC0, CC BY, CC BY-SA were kept. No SVGs.
- I re-checked 40 of the 195 (every ~5th) against the live API: licence and width matched in all 40.
- **Nobody opened the images.** Titles and API metadata only, except about 10 that one batch opened. Four wrong files were caught that way (a pub called "Duke of Wellington", a dog breed "Laika", dumplings called "Jiaozi", a mural photo of Rivera) and dropped. Expect a few more like that: the writer should look at each picture when wiring it in, especially the ones named in the doubts below.
- Dropped by me after review: old 217 Guernica (the file is a photo of a tile replica of a copyrighted work).
- Authors shown as "Unknown author" in the API (Adam Smith portrait, Bismarck 1885 photo): PD is listed but check by hand.

## "Preoblikovati?" meaning

"da" = the picture gives away the answer (usually a portrait or statue of the answer), so the question needs rewording; the suggested Croatian wording is in the block (mostly "Tko je na slici?" style). "ne" = the picture can go with the question as written.
